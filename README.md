# Task 3 - HTML & CSS

## Description

This project demonstrates basic HTML and CSS concepts such as:

- HTML heading tags
- Paragraphs
- Lists
- CSS element selectors
- CSS class selectors
- CSS ID selectors
- Text colors
- Background colors
- Font size
- External CSS

## Files

- `index.html` - Contains the HTML structure of the webpage.
- `style.css` - Contains the CSS styling.
- `README.md` - Contains information about the project.

## Requirements Implemented

1. Created `index.html` and `style.css`.
2. Connected `style.css` with `index.html`.
3. Set the body background color.
4. Created three heading elements with the `head` class.
5. Applied dark blue text color to the `head` class.
6. Added a light green background to the second heading using the `bglime` ID.
7. Changed the `head` text in the second heading to red.
8. Created three paragraphs and styled them using the `p` element selector.
9. Used the `para` ID to customize the second paragraph.
10. Changed the `paragraph` text in the second paragraph to black and increased its font size.
11. Created lists and styled the links using the `a` element selector.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
